## 步骤 3：替换具体表达

| 位置 | 改为 |
|---|---|
| RA 入口 | 小决策树：先消费明确入口/恢复→最终交付目标→开发承诺→设计空间；路由仍建议式，报告出口不被误作实施 |
| quick-fix | 诊断→升级判断→用户裁决→契约明确性→改变/不变→共同收尾；未知必须回澄清，不画成“不变” |
| executing-plans | 首次/恢复→持久模式→当前任务/组/并发；终端档案不可回到业务调度 |
| spec-lifecycle | 事件/新 spec 状态/旧 spec 标注/下一步四列表；pending 不是状态枚举；激活和真实交付分别列出 |
| writing-plans | 合并只有链接的标题为动作/必读资料表，保留相对链接和读取时机 |
| TDD/README | 行为变化先有效红；纯重构保绿；例外遵循唯一清单及可追溯授权 |
| 搜索/语言摘要 | 短规则＋直达权威；明确用户语言优先、增量保持原语言，检索降级仍按原规则 |

可直接采用的准确短句：

> 探索主题按需求确定；在途代理数受平台容量限制，必要时分批完成。
>
> 由真实命令和明确断言判定结果，不依赖模型判断。
>
> 调查前说明对象、方法和预期证据。有证据支持、排除或区分候选时继续；没有证据进展时，汇总原始输出和缺失条件，交用户决定下一步。
>
> 输出语言：用户显式指定（含平台语言设置）优先，其次跟随近期对话，否则使用英语。新产物使用创建时语言，增量修改沿用原文语言；固定话术按语义表达。
>
> 外部检索先用 anysearch；不可用时按链接中的搜索与降级规则执行。

每个 Mermaid 图旁保留同义短文，控制在单一决策主题；不要把所有字段和异常挤成全仓大图。中英文 README 同步语义，不要求逐字翻译；openai 摘要只承担触发/职责，细节链接至权威。
