## 步骤 3：实现绑定读取与小型 CLI

- `readBinding` 从 authority 的原 progress 或旧单文件范围块取得记录；用 scope_commit 的静态投影核对 digest/spec 版本、task、授权来源。
- 本地校验 actual Git root、worktree Git dir、分支、current/claim；receipt 仅引用，不自己授权。多个任务时必须显式 --task，不猜第一张未完成票。
- 分文件 binding 新增为严格可选字段；未知键仍拒绝，历史不迁移。绑定内容只由主线程写状态，CLI bind 只激活引用，不偷偷提交 progress。
- authority 是调用 bind 前已存在的提交，receipt 不把自己写回该提交。并发 claim 检查点按 index 的双基线关系核验；不能更改 validated_commit 来迁就绑定。

CLI 的本地回执发布主体：
```js
export function activateReceipt(repo,reference){
 const view={readText:p=>readFileSync(path.join(repo,p),'utf8')};
 const binding=readBinding(repo,reference,view);
 const target=execFileSync('git',['-C',repo,'rev-parse','--git-path','spec-dev-task.json'],{encoding:'utf8'}).trim();
 const absolute=path.resolve(repo,target),tmp=absolute+'.tmp';
 if(existsSync(absolute)){
  const old=parseUniqueJson(readFileSync(absolute,'utf8'));
  if(old.plan!==reference.plan||old.task!==reference.task)throw new Error('another task receipt is active');
 }
 writeFileSync(tmp,JSON.stringify(reference)+'\n',{flag:'wx'});
 renameSync(tmp,absolute);
 return {ok:true,receipt:absolute,binding};
}
```
CLI 分派参数只接受文档列出的键，stdout 为 JSON，业务拒绝 exit1、用法错误 exit2。clear 先核对原 receipt 与真实工作区，再仅删除该局部引用；不清状态、不删目录。不支持形态不写半个 receipt。

readBinding 返回已核验 `{plan,task,authority,scope_commit,scope_digest,specs:string[],writes:Set<string>,worktree,branch,claim_key}`；CLI JSON 将 writes 转数组。clear 可清理本工作区本计划的过期引用，但不能要求旧范围仍有效才能解除它，也不能删除别的任务引用。

## 步骤 4：CLI 绿与真实版本反例

fixture 加入 `import {scopeFingerprint} from '../../../guardrail/lib/task-scopes.mjs';`（此时 T02 已存在）和如下方法，先构造 `const f={root,feature,plan,spec,state,scopes,setScopes,put,git,commit,save,run};`，安装 bind 后 return f；不能手写已通过结果。
```js
f.bind=(task='T01')=>{
 const scope_commit=f.git('rev-parse','HEAD');
 const view={readText:p=>{
  try{return execFileSync('git',['-C',f.root,'show',scope_commit+':'+p],{encoding:'utf8'});}catch{return null;}
 }};
 const scope_digest=scopeFingerprint(view,f.plan,task).digest;
 f.state.tasks[task].binding={scope_commit,scope_digest,authorization_ref:'fixture-explicit-execution',worktree:f.root,branch:f.git('branch','--show-current'),claim_key:null,claim_checkpoint:null};
 const authority=f.save();
 const r=f.run('guardrail/task-binding.mjs',['bind','--plan',f.plan,'--task',task,'--authority',authority]);
 if(r.status!==0)throw new Error(r.stdout+r.stderr);
 return {authority,...JSON.parse(r.stdout)};
};
```
blob 读取不得用会 trim 的 f.git 包装，以免剥掉有意义的换行。
