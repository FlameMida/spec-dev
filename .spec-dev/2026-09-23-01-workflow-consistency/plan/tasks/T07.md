普通记录核心片段（new directory 使用拒绝覆盖的 mkdir，argv 不经过 shell）：
```js
const result=spawnSync(argv[0],argv.slice(1),{cwd:repo,encoding:null});
for(const [name,bytes] of [['stdout',result.stdout??Buffer.alloc(0)],['stderr',result.stderr??Buffer.alloc(0)]]){
 writeFileSync(path.join(directory,name+'.log'),bytes,{flag:'wx'});
 record[name]=relative+'/'+name+'.log';
 record[name+'_sha256']=createHash('sha256').update(bytes).digest('hex');
}
if(result.error||!Number.isInteger(result.status)){
 writeFileSync(path.join(directory,'incomplete.json'),JSON.stringify({command:argv,exit_code:result.status,signal:result.signal,error:result.error?.message??null,stdout:record.stdout,stderr:record.stderr})+'\n',{flag:'wx'});
 return {ok:false,record:null,exit_code:result.status};
}
record.exit_code=result.status;
writeFileSync(path.join(directory,'record.json'),JSON.stringify(record,null,2)+'\n',{flag:'wx'});
```
record 先取得真实 commit/tree/cwd 与任务/phase/scope；命令运行后核对受测树和范围外 dirty，异常保留原始输出并返回不完整，不能产出“可用 pass”。CLI 对 ok:false 返回非零，不把信号终止伪造为 exit1 的完整测试回执。verify 校验路径留在 feature、原件哈希、版本/范围和 command；使用已存在 Git 对象，不猜 SHA。按 index 支持精确的生成报告 output 声明，新增其它文件仍失效；不把全部 `.spec-dev` 或 Markdown 排除。导出 businessTree 的原十字段树算法供 T09/T16 使用，不以范围指纹替换历史组 tree。
