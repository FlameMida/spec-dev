test('S07 current ordinary task is resumed before an independent pending task',()=>{
 const f=fixture();try{

## 步骤 3：修复优先序并保留专属模式

在 readyTasks 的 bootstrap/active_group 分支之后、普通遍历之前加入：
```js
if(!s.execution && s.current!==null){
 const t=s.tasks[s.current];
 if(t.status==='blocked')return [];
 if(t.status==='in_progress'){
  const row=p.byId.get(s.current);
  return row.deps.every(completed)?[s.current]:[];
 }
}
```
shape 校验仍要求 completed commit，但不要求 in_progress commit。普通串行同时多个未解释 in_progress 为不一致；parallel 的 claim/current 语义不套此限制。

绑定 CLI 增加实际恢复核对：v1 current/in_progress 可无完成 SHA；有 commit 只证明已有提交，不自动写 completed；current blocked 未解除不激活另一张 pending。旧单文件按稳定 task key 取任务，既有授权来源直接使用；缺静态块由主线程在原计划中补当前/未执行项后提交，不由 CLI 批量改稿。

旧单文件静态投影：只在已识别任务正文内归一化行首 checkbox 状态；代码 fence 里的 checkbox 样例不当运行状态。资源/授权记录不唯一、标题重复、unsupported syntax 返回具体错误。status 的计数仍来自原复选框，不被新 scopes block 干扰。
