### 任务 0:建立隔离工作区

**文件**:无(环境动作)

**接口**:
- 消费:计划头部「相关测试范围」声明
- 产出:worktree `.worktrees/plan-2026-08-27-01-plan-single-format`(分支 `plan/2026-08-27-01-plan-single-format`)

**步骤 1:检测已有隔离**

运行:`git rev-parse --git-dir` 与 `git rev-parse --git-common-dir`
两者不同、且 `git rev-parse --show-superproject-working-tree` 无输出(排除 submodule)
→ 已在隔离工作区,跳过本任务。

**步骤 2:建立 worktree**

有原生 worktree 工具(如 EnterWorktree)或 using-git-worktrees skill 时优先使用;否则手工降级:
确认 `.worktrees/` 已被忽略(`git check-ignore -q .worktrees`,未忽略先加入 `.gitignore` 并提交),然后
`git worktree add .worktrees/plan-2026-08-27-01-plan-single-format -b plan-2026-08-27-01-plan-single-format` 并切换到该目录。

**步骤 3:安装依赖并验证基线**

本仓库为纯文档+node 脚本仓库,无依赖安装步骤(node 内置测试框架)。按计划头部「相关测试范围」运行基线验证:

```bash
node --test scripts/tests/*.test.mjs
bash scripts/tests/visual-path.test.sh
node scripts/validate-skills.mjs
node scripts/check-openai-sync.mjs
node scripts/check-plugin.mjs
```

预期:全部通过(基线绿)。基线失败 → 停下报告,先问再继续。

**步骤 4:提交 progress.yaml 初始状态**

将 `progress.yaml` 的 `current` 置 `T00`、T00 状态置 `completed` 后随本任务提交:

```bash
git add .spec-dev/2026-08-27-01-plan-single-format/plan/
git commit -m "feat(T00): 隔离工作区建立（分文件形态计划首任务，progress.yaml 初始化）"
```
