**步骤 1：确认授权和隔离事实**

使用 using-git-worktrees 的现行规则。先读取本计划 index/progress/spec，不预读后继任务正文。只有用户明确开始执行才做本票。

```bash
rtk git status --short
rtk proxy git rev-parse --show-toplevel --git-dir --git-common-dir --show-superproject-working-tree
rtk git branch --show-current
rtk git worktree list --porcelain
rtk git rev-parse HEAD
```

记录原始 HEAD、来源分支/目录；规范化 git-dir 与 common-dir，二者不同且无 superproject 才算已有隔离。已有独立环境先核验用途/状态，沿原环境继续且不取得清理所有权；不能只凭目录名判断。来源脏改保留，不 reset/stash/clean；与本票重叠时先明确所有权。

**步骤 2：建立本计划拥有的 worktree**

不存在可复用隔离时执行：

```bash
rtk proxy git check-ignore -q .worktrees
rtk git worktree add .worktrees/plan-2026-09-07-01-plan-decomposition -b plan/2026-09-07-01-plan-decomposition
```

两条命令分开核验，忽略检查非零时先确认原因。确属未忽略则用下面完整补丁逻辑加入规则，窄暂存 `.gitignore`，跳过发版提交，再创建工作区；已有同名目录/分支不得覆盖，先核验恢复身份。

```python
from pathlib import Path
p=Path('.gitignore');s=p.read_text() if p.exists() else ''
if '.worktrees/' not in s.splitlines():p.write_text(s.rstrip()+'\n.worktrees/\n')
```

```bash
rtk git add .gitignore
rtk proxy env SKIP_RELEASE_HOOK=1 git commit -m "chore: ignore isolated worktrees"
```

之后每条实施命令的 cwd 为 `/Users/maverick/feature-dev/.worktrees/plan-2026-09-07-01-plan-decomposition`。本计划是普通 v1 计划；若遇非 Git/权限拒绝，按原隔离降级记录原因，不将降级用于本项验收中的 v2 组夹具。当前主仓可用，计划不预设会降级。
