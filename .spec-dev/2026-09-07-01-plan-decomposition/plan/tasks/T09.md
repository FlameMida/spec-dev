### T09：全量安全网、本地交付与资源清理

**文件**：本特性 spec/progress/执行与验收证据、三份旧 spec、roadmap；没有产品改动时只做文档交付。

**接口**：
- 消费：T08 必需矩阵与独立审查通过、原始 base_commit、资源所有权、七条部分取代映射。
- 产出：最终全量证据、本地来源分支的实际合并提交、资源处置、sync_commit 与 roadmap delivered。

由 executing-plans 收尾处置完成后执行，不进入实施票连续循环。交付限定本地，未授权 push；不能把计划完成或测试完成当作实际合并完成。

**步骤 1：最终全量验证与失败归属**

停止本次所有模型/证据写入进程，先保存 T08 证据提交，确保测试运行期间无后台写者。用 index 日志包装器记录完整 Node 命令，运行前将命令数组展开为排序后的所有 `scripts/tests/*.test.mjs`；不能只跑新增三项。无进程时记录事实，不能凭空编造 PID。

```bash
rtk proxy node --test scripts/tests/*.test.mjs
rtk proxy node scripts/validate-skills.mjs
rtk proxy node scripts/check-plugin.mjs --codex-validate
rtk proxy node scripts/validate-output.mjs plan-index .spec-dev/2026-09-07-01-plan-decomposition/plan

```

预期全部 exit 0、真实测试数大于零、fail/skip 均为0。范围内失败回所属票修复、复跑并按影响面复验；范围外失败在干净来源分支复跑单条失败命令，来源有脏改先与用户确认，不为复跑覆盖它。来源同失败则列为既有失败交用户裁决是否阻塞；来源通过则本次回归。失败和归属输出全部保留，不标假 PASS。若 T08 已在相同候选树、全部写者停止后运行同一完整套件，复用该次真实证据并注明，不无理由重复长测试。

**步骤 2：保守退役检查**

只查 index 相关范围内测试，以当前 active spec 的现行 Scenario 名匹配。仅“同名现行 Scenario 不存在”且“旧 Requirement 已 REMOVED/Superseded 或整份 spec 已 superseded”同时成立才列孤儿候选；不按此命名的历史测试豁免。本项保留普通 v1 回归，四查旧断言已由 T05 原位更新，不将测试文件整份删除。候选非空列精确测试名、旧 Requirement、现行对照并征得删除授权；未获授权保持。空则记录无孤儿测试。

**步骤 3：按批准映射回写部分取代**

仅在必需验收及审查均通过后运行；三份旧 spec 保持 active，seven Requirements 正式取代，不改其他 pending 或旧 sync_commit。下面完整脚本定位标题，保留括注，移除只指向本 spec 的 pending 并添加精确标记。若已经回写，验证内容后幂等跳过。

```python
from pathlib import Path
import re,datetime
new='.spec-dev/2026-09-07-01-plan-decomposition/spec/plan-decomposition-design.md'
mapping={
'.spec-dev/2026-09-06-01-concurrent-execution/spec/concurrent-execution-design.md':{'plan 单一形态':'M01','渐进执行与断点恢复':'M02','集成验证后才完成':'M03'},
'.spec-dev/2026-09-06-02-tdd-seam/spec/tdd-seam-design.md':{'红绿循环与重构分离':'M04','收尾纯重构的行为保护':'M05'},
'.spec-dev/2026-08-26-01-major-upgrade/spec/major-upgrade-design.md':{'设计原则声明块':'M06','roadmap 上下文胶囊':'M07'}}
date=datetime.date.today().isoformat()
for name,items in mapping.items():
 p=Path(name);s=p.read_text()
 for title,mid in items.items():
  pattern=r'^### Requirement: '+re.escape(title)+r'(?:（[^\n]*）)?$'
  matches=list(re.finditer(pattern,s,re.M));assert len(matches)==1,(name,title)
  m=matches[0];end=s.find('\n### Requirement:',m.end());section=s[m.end():end if end!=-1 else len(s)]
  if re.search(r'^> \*\*Superseded \(',section,re.M):
   assert new in section and mid in section,(name,title,'different successor');continue
  marker=f'\n\n> **Superseded ({date})** — 此 Requirement 由 {new} 的 {mid} 取代；其余现行条款继续有效。'
  s=s[:m.end()]+marker+s[m.end():]
 s='\n'.join(line for line in s.split('\n') if not ('Superseded-pending' in line and new in line))
 p.write_text(s)
```

逐条核对七标记及现行共存判据，连同本 spec 实施记录与验收指针提交；整个取代提交组随本地合并生效。不将 pending 当 delivered，不将旧整份 spec 翻 superseded。
