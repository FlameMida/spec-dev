### 任务 3：plan-index 任务文件行数上限

**文件**：
- 修改：`scripts/validate-output.mjs:228-233`（`validatePlanIndex` 内 `files` 计算之后）
- 测试：`scripts/tests/plan-index.test.mjs`（追加两例）

**接口**：
- 消费：T02「计划体量」节的常量 200
- 产出：plan-index 错误项 `{ path: "tasks/TNN.md", expected: "<= 200 lines", actual: "N lines" }`，退出码 1

**步骤 1：写失败测试**

在 `plan-index.test.mjs` 末尾追加（复用文件顶部已有的 `makePlan`、`runCapture`、`run`、`writeFileSync`、`rmSync`、`path`）：
```js
const lines = (n) => Array.from({ length: n }, (_, i) => `line ${i + 1}`).join("\n") + "\n";
test("S1.2 任务文件超过 200 行被拦截", () => {
  const dir = makePlan(["| T01 a | — | — | f() |"], ["T01.md"]);
  writeFileSync(path.join(dir, "tasks", "T01.md"), lines(201));
  try {
    const r = runCapture(dir);
    assert.equal(r.status, 1);
    assert.match(r.stderr, /tasks\/T01\.md/); assert.match(r.stderr, /<= 200 lines/); assert.match(r.stderr, /201 lines/);
  } finally { rmSync(dir, { recursive: true, force: true }); }
});
test("S1.2 恰好 200 行通过", () => {
  const dir = makePlan(["| T01 a | — | — | f() |"], ["T01.md"]);
  writeFileSync(path.join(dir, "tasks", "T01.md"), lines(200));
  try { assert.equal(run(dir), 0); } finally { rmSync(dir, { recursive: true, force: true }); }
});
```

**步骤 2：运行测试确认失败**

运行：`rtk proxy node --test scripts/tests/plan-index.test.mjs`
预期：「超过 200 行被拦截」FAIL 为 AssertionError：`0 !== 1`（校验尚未拦截）；「恰好 200 行通过」PASS；其余既有用例 PASS。

**步骤 3：写最小实现**

`validate-output.mjs` 在
```js
  const files = readdirSync(tasksDir)
    .filter((f) => /^T\d\d.*\.md$/.test(f))
    .map((f) => f.match(/^T\d\d/)[0]);
```
之后插入：
```js
  // 单任务文件上限（writing-plans「计划体量」）：超限报错，逼迫拆任务或收敛片段
  const TASK_LINE_CAP = 200;
  for (const f of readdirSync(tasksDir).filter((f) => /^T\d\d.*\.md$/.test(f))) {
    const count = readFileSync(path.join(tasksDir, f), "utf8").replace(/\n$/, "").split("\n").length;
    if (count > TASK_LINE_CAP) errors.push({ path: `tasks/${f}`, expected: `<= ${TASK_LINE_CAP} lines`, actual: `${count} lines` });
  }
```
文件头部用法注释第 6 行句尾追加「、单任务文件 ≤ 200 行」。

**步骤 4：运行测试确认通过**

运行：`rtk proxy node --test scripts/tests/plan-index.test.mjs && rtk proxy node scripts/validate-output.mjs plan-index .spec-dev/2026-09-12-01-workflow-slimming/plan`
预期：测试全部 PASS；本计划自身校验输出 `"ok": true`。
