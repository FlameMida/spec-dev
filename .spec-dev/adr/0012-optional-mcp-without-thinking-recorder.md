# ADR-0012: 外部 MCP 按需配置与推理记录器退役

**Status**: Accepted (2026-10-23)
**Supersedes**: ADR-0003

## 背景

原 ADR-0003 以 vendored sequential-thinking 替代外部推理 MCP。小任务消融观察到记录开销，未显示正确性收益；用户随后明确决定移除整个 skill。该实验不证明所有长任务均无损，但已不再采用“默认保留记录器”的取舍。

## 决定

插件不要求或注册全局外部 MCP 服务。受控审查可按需生成本地 stdio 工具配置；浏览器和性能验收所需 MCP 由项目按实际能力配置，缺失时使用既有可行工具或如实标记未验证范围。不同平台沿统一 skill 工作流和已有能力映射执行。

不分发 sequential-thinking、对应 MCP、默认调用、运行时诊断或专属 SHA 快照同步路径。主线程继续核对证据、消解冲突和比较方案，不以额外的编号思考记录作为完成条件。AnySearch 及其上游同步行为保持不变。

## 取舍

不再承担独立推理记录器的分发和调用成本，也不承诺保留其持久状态能力。未来若出现具体的长任务恢复需求，应依据实际工作流与证据另作决定；不因“复杂问题”标签自动恢复工具依赖。此前“仅移除默认调用、保留整个 skill”的方案已由用户选择整体移除而替代。
