在隔离工作区用 `rtk proxy python3 - <<'PY'` 执行以下 Python 块（尾部补单独一行 `PY`），只先改 eval/测试。条目已经把 GIVEN/WHEN 转为输入、THEN 转为独立期望；保留其他条目。

```python
import json

      "expected_output": "可先获得 typecheck 反馈，仍运行本票红绿与相关验证；最终全量保留，静态通过不解锁尚未完成集成验证的后继。"
    },
    {
      "id": "tdd-seam-s12",

    }
  ]
}''')
for name, entries in additions.items():
    path = Path(name)
    data = json.loads(path.read_text())
    present = {entry['id'] for entry in data['evals']}
    assert not present.intersection(entry['id'] for entry in entries), name
    data['evals'].extend(entries)
    path.write_text(json.dumps(data, ensure_ascii=False, indent=2) + '\n')
```
