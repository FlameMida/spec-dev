**步骤 1：检测已有隔离**


**步骤 2：建立并登记 worktree**

执行时优先 using-git-worktrees 的原生工具；本环境没有原生创建工具，采用以下明确路径。`.worktrees/` 已在根 .gitignore 中；先核实忽略生效。progress.resources 已预登记目标，创建前核对路径/分支均未占用。

```bash

rtk git rev-parse HEAD
rtk git worktree add .worktrees/plan-2026-09-06-03-review-conformance -b plan/2026-09-06-03-review-conformance
```

原始 base_commit 记录创建前来源 HEAD。后续命令 cwd 固定 `/Users/maverick/feature-dev/.worktrees/plan-2026-09-06-03-review-conformance`；再次运行 `git rev-parse --show-toplevel` 与 `git branch --show-current` 核对实际绑定。若来源已不是 main，按事实修正记录，不能假装计划静态文字就是实际来源。
