# Domain Term Format

> 读取时机：准备记录领域术语时；位置、权限和冲突处置以 [统一文档规范](../../../requirement-analysis/references/document-conventions.md) 为准。

## 示例条目

```markdown
- **订单**：客户提出的一次商品采购请求。_Avoid_：采购单。适用域：交易。来源：已批准设计或当前用户决定的可恢复引用。
```

共享术语进入 `.spec-dev/glossary.md`，局部术语进入对应 spec。
术语只解释“是什么”，定义简短；不收通用编程概念、数据库表名或接口实现细节。
同名不同义以适用域区分，不机械要求跨域唯一。
有自然分组时可用小节；没有内容不创建空文件。
已有 CONTEXT.md 或其他词汇表不自动迁移；遇到真实冲突按统一规范处理。
